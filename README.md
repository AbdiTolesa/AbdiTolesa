### Hi, I'm Abdi 👋

WordPress engineer focused on plugin development and the **block editor (Gutenberg)**. I build blocks, editor sidebars and settings UIs in React on top of `@wordpress/*` packages, and the PHP and REST APIs behind them.

#### Block editor work

- **[wp-quote-blocks](https://github.com/AbdiTolesa/wp-quote-blocks)**: a custom block with five layout variations and a variation picker. It uses core typography supports with the **Font Library** (it replaced a Google Fonts API integration, with a block deprecation that migrates existing content), puts its style controls in core's Styles tab panels (`InspectorControls` groups), and has an **Interactivity API** copy-to-clipboard button (`viewScriptModule`, generator actions, context).
- **[multi-column](https://github.com/AbdiTolesa/multi-column)**: a block for laying out content in newspaper-style columns.
- **Professional**: I work on **[Rank Math SEO](https://wordpress.org/plugins/seo-by-rank-math/)**, used on millions of WordPress sites. My work includes its block editor integration: editor sidebar panels, data stores, and React-based admin and settings screens.
